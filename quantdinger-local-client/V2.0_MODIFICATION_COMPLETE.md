#### _save_config() - 简化
```python
def _save_config(self):
    """Save configuration from UI."""
    self.config_mgr.set('api_key', self.api_key_var.get())
    self.config_mgr.set('cloud_api_url', self.cloud_url_var.get())
    self.config_mgr.set('cloud_url', self.ws_url_var.get())
    self.config_mgr.set('broker', self.broker_var.get())
    
    try:
        self.config_mgr.save()
        self._log("✓ 配置已保存")
        messagebox.showinfo("成功", "配置保存成功！")
    except Exception as e:
        messagebox.showerror("错误", f"保存配置失败: {e}")
```

## ✅ 优势对比

### v1.0 vs v2.0

| 特性 | v1.0（登录模式） | v2.0（API Key模式） |
|------|-----------------|-------------------|
| **Session冲突** | ❌ 网页端会被踢出 | ✅ 无冲突，多端共存 |
| **配置复杂度** | ⚠️ 需要用户名+密码 | ✅ 只需API Key |
| **安全性** | ⚠️ 密码存储风险 | ✅ 只存储API Key |
| **用户体验** | ⚠️ 两次登录操作 | ✅ 一次复制粘贴 |
| **代码维护** | ⚠️ 较复杂 | ✅ 更简洁 |
| **依赖库** | ⚠️ 需要api_client.py | ✅ 无需额外依赖 |

## 🎯 使用流程

### 用户操作步骤

1. **在Web后台获取API Key**
   - 登录 http://39.105.150.99:8888
   - 进入个人中心 → 交易所配置
   - 点击"获取Key"按钮
   - 复制API Key（只显示一次！）

2. **配置桌面客户端**
   - 打开客户端
   - 粘贴API Key到"API 密钥"输入框
   - 选择券商类型（simulation/mt5/ibkr）
   - 点击"💾 保存配置"

3. **启动客户端**
   - 点击"▶ 启动"按钮
   - 开始接收交易信号

## ✅ 总结

### 架构决策

**问题**：桌面客户端和网页端使用相同的JWT Token认证，导致Session冲突。

**解决方案**：采用API Key认证机制，避免Session冲突，实现多端共存。

**优势**：
1. ✅ 网页端和客户端可以同时使用
2. ✅ 用户体验更好（一次配置即可）
3. ✅ 代码更简洁（减少~90行代码）
4. ✅ 安全性更高（不存储密码）
5. ✅ 维护成本更低
